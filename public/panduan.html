info 1. Pendahuluan

SINORA (Sistem Informasi Penomoran Surat Administrasi) adalah aplikasi berbasis web yang dirancang khusus untuk mempermudah penomoran, pencatatan, pengarsipan, dan pengelolaan agenda surat-menyurat di lingkungan Rumah Tahanan Negara Kelas IIB Painan.

Dengan SINORA, penomoran urut surat masuk/keluar dilakukan secara otomatis dan transparan sehingga mencegah duplikasi nomor serta mempermudah pencarian arsip secara real-time.

badge 2. Hak Akses Pengguna (Role)

Aplikasi SINORA membagi hak akses ke dalam 3 peran utama:

Peran / Role Deskripsi Akses & Wewenang
Super Admin Akses penuh ke seluruh fitur sistem, termasuk pembuatan & manajemen akun petugas, pengelolaan agenda, dan cetak laporan.
Admin Dapat menambah, mengubah, dan menghapus data agenda surat, serta mengunduh laporan rekapitulasi.
Petugas Dapat menginput agenda surat baru divisi terkait, mencari arsip, serta melihat kalender kegiatan harian.

login 3. Langkah-langkah Login (Masuk Sistem)

1

Buka Peramban / Browser

Akses alamat aplikasi SINORA di peramban komputer/HP Anda (misal: Google Chrome atau Microsoft Edge).

2

Masukkan ID User / NIP & Password

Ketikkan Username atau NIP terdaftar serta kata sandi akun Anda pada kolom login.

3

Klik Tombol "Masuk Sistem"

Sistem akan memverifikasi akun Anda dan mengarahkan ke halaman Dashboard Utama.

lightbulb
Penting: Jika lupa kata sandi atau akun terblokir, hubungi Admin/Tim TI Rutan Kelas IIB Painan untuk melakukan reset password.

edit_note 4. Pengelolaan Agenda & Penomoran Surat

Menu Agenda adalah pusat pencatatan surat administrasi Rutan Kelas IIB Painan.

Cara Menambah Agenda Surat Baru:

  1. Klik tombol "+ TAMBAH AGENDA BARU".
  2. Isi formulir yang tersedia:
    • Nomor Surat: Isikan nomor resmi surat.
    • Tanggal: Pilih tanggal surat/kegiatan.
    • Alamat Surat: Isikan instansi pengirim atau tujuan.
    • Keterangan Isi Surat: Perihal ringkas isi surat.
    • Divisi: Pilih bagian pemilik surat (KPR, Pengelolaan, atau Pelayanan Tahanan / Kamtib).
  3. Nomor Urut akan terisi secara otomatis oleh sistem.
  4. Klik "Simpan Agenda".

Pencarian & Filter Tab:

Gunakan kolom pencarian di atas tabel untuk mencari surat berdasarkan nomor, nama instansi, atau kata kunci. Gunakan tab Hari Ini, Mendatang, atau Arsip untuk menyaring data dengan cepat.

calendar_month 5. Kalender Agenda (Calendar View)

Tampilan kalender menyajikan ringkasan kegiatan dan surat dalam format bulanan.

  • Tanggal hari ini disorot dengan warna khusus (Biru).
  • Arahkan kursor ke label agenda pada tanggal tertentu untuk melihat perihal kegiatan secara mendetail.

group 6. Manajemen User / Akun Petugas

Fitur ini digunakan oleh Super Admin / Admin untuk mengelola anggota yang terdaftar di aplikasi.

1

Membuat Akun Baru

Klik "+ Buat Akun Baru", masukkan Username, Nama Lengkap, NIP, Divisi, Role (Petugas/Admin), dan Password awal.

2

Mengedit / Nonaktifkan Akun

Gunakan tombol edit (✏️) untuk mengubah info petugas, atau hapus (🗑️) jika petugas mutasi/nonaktif.

print 7. Cetak Laporan & Export PDF

Untuk mencetak rekapitulasi agenda surat resmi:

  1. Buka menu Reports.
  2. Periksa pratinjau rekapitulasi data.
  3. Klik tombol "Cetak / Download PDF".
  4. Pilih printer fisik atau opsi "Save as PDF" untuk mengunduh berkas digital.

help 8. Tanya Jawab (FAQ)

Q: Apakah aplikasi ini bisa dibuka di HP?

A: Ya, aplikasi SINORA dirancang responsif dan dapat diakses dari browser HP, tablet, maupun komputer/laptop.

Q: Bagaimana jika terjadi kesalahan penginputan nomor surat?

A: Petugas atau Admin dapat menekan tombol edit (✏️) pada tabel agenda untuk memperbaiki nomor atau perihal surat.
